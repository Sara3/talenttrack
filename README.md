# TalentTrack

Every candidate on one board. Built by Warm Intro Knights for the hackathon.

Live demo: https://sara3.github.io/talenttrack/

A single-page applicant tracker: candidate board with stage aging, interview scorecards, start-date and ramp planning, plus AI recruiter, scheduler and interviewer tools. Data is saved in each visitor's browser and every new visitor starts with demo data.
